# HelloWorld

Win11 摘录式阅读软件原型（单文件版）。

## 运行

```bash
python3 -m http.server 8000
```

然后打开：`http://localhost:8000/app.html`

## 已实现（原型）

- 左侧阅读区：支持导入 txt/md，pdf 内嵌打开，docx 预留说明。
- 在左侧选择文本后，可点击浮动按钮创建右侧摘录块。
- 点击摘录块「回到原文」可定位并高亮来源选区。
- 摘录块可拖动。
- 摘录块边缘连接点可拖拽到另一摘录块，创建连线。
- 连线随摘录块移动保持连接，选中连线后按 Delete 删除。
