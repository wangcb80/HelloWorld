# HelloWorld

Win11 摘录式阅读软件增强原型（单文件版）。

## 运行

```bash
python3 -m http.server 8000
```

打开 `http://localhost:8000/app.html`。

## 当前已实现（增强原型）

- 左侧阅读区：
  - `txt/md` 可直接加载阅读
  - `pdf` 可内嵌预览
  - `docx` 为占位（已预留后续解析接入点）
- 选中左侧文本后可一键创建右侧摘录块。
- 摘录块支持：标题编辑、正文编辑、拖拽移动、删除。
- 点击摘录块“回到原文”可在左侧定位并高亮来源文本。
- 摘录块边缘连接点支持拖拽连线，目标卡片高亮吸附提示。
- 连线带关系标签（创建时输入），可选中后按 `Delete` 删除。
- 画布数据支持：
  - 浏览器本地保存/恢复（localStorage）
  - 导出 JSON
  - 从 JSON 导入
  - 一键清空

## 快捷操作

- `Delete`：删除当前选中的卡片或连线
- `Esc`：取消当前连线操作
